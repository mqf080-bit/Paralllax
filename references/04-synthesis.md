# 从参考到 Parallax：能拍板的，和还不能拍板的

> 如果只读一篇，读这篇。前面三篇是证据，这篇是结论。

> **2026-10-26 注**：本文的「槽 / 槽壁 / 槽底」是 2026-10 早期方案。腰高 4 轨可读性验收后**不再挖槽**，
> 文中这些词一律按「台面 / 轨面」理解；① 的「必须有槽壁」已明确作废。

## 1. 参考已经能拍板的 6 条

### ① ~~轨道必须有实体边界，不能是线~~（2026-10-26 作废）

> **作废**：腰高 4 轨可读性已在 Quest 3 验收通过。实际方案是**细分割线 + 0 / 5 暗一档 +
> 窗口随 shift 整体滑动**，台面不挖槽、键浮在台面上；不需要槽壁。下面这段只保留为历史记录。

Arcaea 用 3 条纵向细线 + 透视收敛读出 4 轨；Beat Saber 干脆没有轨道线，靠方块的位置和朝向。
这两种做法在 **2D / 稀疏谱面** 里都成立，但都不适用于「腰高 + 4 轨可视窗口（物理场 6 轨）+ 密谱 + shift」。

腰高视角是俯视，远端 4 轨会被压缩到一起；shift 又要求玩家看出「窗口整体移动了」。
线提供不了遮挡和视差，只有**槽壁**能。4 轨窗口的实体边界不是造型选择，是读谱前提。

### ② 判定面是材质状态，不是几何体

Phigros 的判定线可以随便转，因为它是画面里唯一的高对比元素。
Parallax 的画面里有金属高光、玻璃内光、釉面反光——再加一根发光的线，就会和键抢注意力。

判定应该表现为**槽底被照亮的一段带**：
- 它没有厚度，不参与遮挡；
- 它随槽走，不独立运动；
- 它是「状态」，不是「物件」。

这条同时解决了 4.5 的「判定层不得失读」：槽体不动，判定带就不会跑。

**硬规则**：常态下判定线相对槽底不动。只有愚人节 / 搞笑谱面允许偏移；shift 是窗口整体平移，不算「线动」（见 `parallax-idea.md` 5.1）。

### ③ 左右手用颜色/釉色编码成立，但必须有冗余

四款游戏都在做同一件事：

| 游戏 | 编码 |
| --- | --- |
| Arcaea | 蓝 / 粉（色盲模式蓝 / 黄） |
| Beat Saber | 红 / 蓝 |
| AUDICA | 蓝 / 橙 |
| Synth Riders | 青 / 品红 |

Parallax 只给要求手别的元素上青 / 赤（hit 用釉、arc 用玻璃）；drag / hold 默认中性（drag 若谱面明确标手别才上色）。颜色一出现就等于锁手（见 idea 5.4）。
但**颜色不能是唯一线索**：暗光、色盲、远距离都会让它失效。需要再加一层位置或形状的冗余（例如左轨的键永远比右轨多一个倒角方向）。

### ④ Arc 需要「体积三件套」才能不丢

Synth Riders 的 rail 是最接近 Arc 的 VR 实现，但它的 rail 很细、很亮，遇到霓虹背景就会丢（见 `vr-rhythm/synth-riders/01`、`05`）。
Arcaea 的 Arc 在 2D 里不丢，是因为它给 ribbon 加了**平切端面 + 边缘高光 + 半透明条身**——它不是一条线，是一条挤出的带。

Parallax 的玻璃管必须同时有：外壁轮廓、内部光带、接触阴影。少一个，就会在金属台面上消失。

### ⑤ 反馈必须局部化

Arcaea 可以在握住 Arc 时让整个轨道轻微倾斜；Parallax 不可以。VR 里全局倾斜 = 晕动。
反馈只能发生在**键/管/槽**的局部：崩瓷、擦雾、灌注、真空段、疤痕。

这条会直接影响 4.5 的「单曲异象」：轨道倾角只属于愚人节 / 搞笑谱面，常规谱面不做；且不得生成障碍物。

### ⑥ HUD 要么消失，要么成为世界里的物件

Beat Saber 几乎没有 HUD；AUDICA 把分数做成浮空数字；Synth Riders 把面板放在轨道尽头。
没有一款把 HUD 贴在「视野边缘的屏幕上」。

Parallax 的「HUD 托架」是第二种。需要先做一个决定：托架固定在**世界**（转头会离开）还是**视野**（永远在边缘）。
- 世界固定：更像仪器，但玩家可能找不到；
- 视野固定：更安全，但会破坏「剖开的仪器」的沉浸感。

目前文档没有答案。这是必须在灰模测试里决定的，不是想出来的。

## 3. 已同步到 `parallax-idea.md` 的修订

这一轮不是建议，是已经写进正文的校正。完整清单见 4.0 的「2026-10-17 校正」表，核心是七条：

1. **键改为浮在台面上**，不嵌进槽里（嵌入会被槽壁吃掉轮廓，也和"用手打"冲突）。
2. **左右手只给要求手别的元素**：hit 用青 / 赤釉，arc 用青 / 赤玻璃；drag / hold 默认中性，不再强行上色。
3. **材质物理校正**：drag 是冰锥（不是带子、不是擦亮）、hold / arc 是玻璃管（不是玻璃条）、黄铜是暖金属高光（不是高饱和色）。
4. **轮廓优先、材质第二**：远距 / 低光 / 色觉差异下，材质会先丢。
5. **判定面是槽底亮带**，不是浮线；黄铜只负责判定瞬间的边缘高光。
6. **体积三件套按几何分类**：方块用顶 / 正 / 侧，冰锥类用尖端 / 棱面 / 接触阴影，管类用端面 / 管壁 / 内部光带。
7. **轮廓也要独立成立**：hit 方砖 / drag 冰锥 / hold 直管 / arc 弯管——去掉材质与颜色，仍然能分出四种键。

手别锁定与高度上限见 §7。

drag 是这轮最关键的校正：它的形态是**琶音用的个体冰锥**，扫过即碎，不是滑条；所有"越擦越长"的写法都已删掉。

硬性限制（判定线相对槽底不动、无障碍物、背景 3D 舞台）另见 §7。

另外，4.1 增加了可检查的「剖切边」：近端与一侧露出层叠与驱动结构——否则"被剖开的仪器"只是一块铣了槽的实心台面，和"剖开"没有关系。

## 5. 下一步：三张构图测试，而不是继续加材质

现在最缺的不是细节，是**构图是否成立**。建议先做三个静态/半动态测试，每个只回答一个问题：

### A. 正视 4 轨窗口（6 轨场）— ✅ 2026-10-26 已被头显验收取代

- 站立，轨道在腰高，空谱面，无键。
- 只测：能不能一眼数清 4 轨；0 / 5 隐藏后，边缘是否还读成「一条轨」而不是「被切掉的轨」。
- **结果**：细分割线 + 0 / 5 暗一档 + 窗口随 shift 整体滑动已经够清楚；**不需要槽 / 槽壁**。
  「槽宽 / 槽深」的变量作废，只保留为当时的测试设计。

### B. 抬头 30° 看 Arc

- 一条 Arc 从腰高升到头顶，再落回。
- 只测：高度上限在哪里被感知；Arc 在最高点时是否还可读；脖子是否愿意抬。
- 变量：Arc 管径 / 内光亮度 / 最高点高度 / 是否有上方横梁。

### C. shift 的瞬间

- 4 轨窗口整体左移一轨：0 出现、4 隐藏；编号与台面保持不动。
- 只测：玩家能不能看出「窗口移动了」，而不是「谱面变了」；移动过程需要多少时间才不晕。
- 变量：移动时长 / 是否有轨道编号 / 槽底是否有刻度。

这三个测试都不需要材质，灰模就够。**先证明构图，再谈仪器。**

## 6. 下一批参考：材质，不是游戏

> 材质参考只借「像」，不做写实复刻；要的是表面行为（吃光、碎裂、留痕），不是 PBR 参数。

游戏参考解决的是「布局与信息」，它解决不了「看起来贵」。4.1 的「被剖开的精密仪器」需要另一批参考：

- **CNC 铣削铝面板**：刀纹方向、倒角、阳极氧化后的颜色厚度；
- **陶瓷釉面**：青釉/赤釉的流动、积釉、开片；
- **玻璃管**：壁厚、端面、内部光带、气泡；
- **镂空机械表**：齿轮、夹板、螺钉——「剖开的精密仪器」的字面参考；
- **专业音频设备面板**：旋钮、刻度、丝印、齿条（Teenage Engineering / Braun 一类）；
- **3D 舞台与体积光**：Synth Riders / AUDICA 的隧道是现成例子，但 Parallax 的舞台要更「仪器」——机械结构、光学台、暗房，而不是霓虹隧道。

这批图应该和游戏参考分开放（例如 `references/materials/`），因为它们的用法不同：
游戏参考用来定**规则**，材质参考用来定**表面**。

## 7. Parallax 的硬性限制（与参考的分界）

| 限制 | 参考里谁违反过 | Parallax 的处理 |
| --- | --- | --- |
| 判定线相对槽底不动 | Phigros 的线会旋转、波动、多条 | 常态固定；只有愚人节 / 搞笑谱面例外 |
| 无障碍物 | Beat Saber 的墙 / 炸弹、Phigros 的 Noise Field | 可打区只有键；背景物件不得进入；愚人节也不破例 |
| 背景可 3D / 动画 / shader | Synth Riders / AUDICA 的隧道与场景 | 允许，但必须待在可打区之外，且明度不超过键 |
| 手别锁定 | Arcaea 换手会让 Arc 变红断连 | 标了左 / 右的元素不允许换手；换手按断连处理；没有例外 |
| 高度上限 | 没有参考有硬上限 | 超过上限的 note 不生成；上限之上不放「看起来可打」的东西；没有例外 |

这五条是「打破规则」的地板：CYCLOTRON 可以打破编排与演出规则，但不打破它们。常规谱面里，背景是唯一允许做大幅度演出性运动的一层；参考系（台面、分割线、判定带）不能动。
