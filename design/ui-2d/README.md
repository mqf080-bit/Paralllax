# Parallax — 2D UI Study 02

在进入 VR 之前，用二维网页把 **A（Technical Console）+ C（Editorial Grid）** 的视觉先试一遍：
更密的网格、更大的字号层级、更明确的留白，以及稀有的 lime 信号色。

## 打开

```bash
cd design/ui-2d
python3 -m http.server 8080
# http://127.0.0.1:8080/
```

直接打开 `index.html` 也可以；页面没有构建步骤。

- `?screen=home|songs|packs|paused|settings|result` 直接进入某个状态；
- 顶部 tabs / 数字键 1–6 切换；
- Songs 列表可点选，右侧详情会更新；
- `How to add packs` 打开加包页。

## 设计方向

- **表面**：石墨底、方角、1px 细线；没有圆角、没有拟物高光、没有玻璃拟态。
- **主强调**：浅蓝 `#9CC8FF`，用于主按钮、选中态、焦点、图表。
- **稀有强调**：lime `#C6F24E`，只用于 `SELECTED` 小标记、暂停状态点、`CLEAR`、chart map 的 shift 线。
- **文字**：Space Grotesk；数字用 JetBrains Mono；大标题负字距，标签用 10–12px 小字距。
- **版式**：12 栏式的非对称双栏；左信息 / 右操作，或左列表 / 右详情；大数字、细线、底部状态条。

## 与 VR 的映射

当前面板是 **1200 × 742**，对应 VR 的 **760 × 470**（约 1.58×）。这意味着：

- 版式、间距比例、颜色可以直接复用；
- **字号不能直接除以 1.58**：二维稿里的 10px 标签到 VR 只剩约 6px。移植到 760×470 时，需要把标签 / 按钮 / 说明提升到 14–20px 的 VR 字号，而不是按比例缩；
- 字体需要随包带到 Quest 浏览器（或退回系统 sans），不能假定 Space Grotesk / JetBrains Mono 存在；
- 二维的 hover 在 VR 里对应激光悬停 + selected 左侧蓝条；二维的点击对应扳机按下。

## 反馈（2026-10-20）

- **有些字体太小**。二维稿里的 9–11px 标签是桌面审阅尺寸，不等于 VR 字号；
- 移植到 760×470 时，标签 / 说明 / 按钮需要整体上调，目标是头显里不靠前倾也能读；
- 下一步先调二维稿的字阶，再把版式搬进 VR，不要直接按 1.58× 缩。

## 现状

- 六个界面都有，并且共用一套 token；
- Songs 列表、详情、加包页、设置 stepper、暂停/结算都是真实布局，不是模板换数据；
- 数据是设计样张，不接游戏状态；
- 筛选 / 排序 / 滚动还没做；
