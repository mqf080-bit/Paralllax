## 锁版怎么构造

不是水印，是**从字里长出来的记号**。三个约束全部来自字的实测包围盒：

| 约束 | 规则 |
| --- | --- |
| 同宽 | 符号左右边界 = 三个字母的包围盒，不缩、不伸出 |
| 同粗 | 描边 = 字干粗细（≈ cap height 的 12.5%） |
| 对齐 | 波纹对齐 cap line，横线对齐 baseline |

符号也是自绘 SVG：`≈` 两波 → `≃` 一波一横 → `≅` 一波两横 → `≡` 三横。
波纹逐级消失，等于“误差在收敛”这件事本身。不依赖字体覆盖。

## 三种摆法

- **ABOVE（推荐）**：整枚记号压在字上方，宽度与字一致，读起来是「≅ CGR」；
- **BELOW**：记号沉到基线以下，像一条签名底座；
- **BEHIND**：旧方案，符号铺在字后面；对比用，不再采用。

## 没定的部分

- 字母词表：`APX / ASM / CGR / IDN` 是当前提案；
- 字体：样张用系统 sans（Space Grotesk 缺失时回退），正式做要选一款 display 字或自绘字形；
- 动效（波纹收拢 / 评级跳动）不在这个样张里。
