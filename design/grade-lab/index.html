构造规则

同宽：符号的左右边界就是三个字母的实测包围盒，不缩、不伸出。 同粗：符号描边 = 字干粗细（≈ cap height 的 12.5%）。 对齐：波纹的对齐基准是 cap line，横线的对齐基准是 baseline。

语义参与布局：波纹 = 还没收敛，横线 = 已经落定。整枚记号压在字的上方， 从 APX 到 IDN，波纹从两条减到零、横线从零加到三条——记号的“抖动”逐级消失。

点进任意一个字母页可以打开「构造网格」，看到 cap line / baseline / 符号行距。
