## 1. 这一版是什么

一块悬空的 10m 长板，4 条轨，没有凹槽、没有边框、没有底座。**没有键型、判定、shift 动画、谱面。**

- **台面**：1092 × 10000 × 12mm 的整板，圆角 + 2mm 倒角。
- **4 轨**：每轨 230mm，分割线 1.6mm 暗线（不是槽，不是导轨）。
- **判定带**：横跨 4 轨的一条冷白光带（柔光 + 芯线），静态。
- **剖切**：近端整面 + 右侧靠玩家 2.4m 的一段敞开；内部有承力底板、中层甲板、纵筋、横梁；切面有 6mm 倒角框与断面端头。
- **浮空显示**：曲名 / 分数 / 物量，世界固定，只有字和一条黄铜细线。
- **材质**：黑阳极铝（拉丝）+ 机加工铝 + 腔体暗色。陶瓷 / 玻璃 / 冰 / 黄铜仍在材质库里，等 Step 2 的键型。
- **环境**：程序化 PMREM 暗房 + 灯带；主光 + 轮廓光 + 台灯 + 10m 跑道补光。
- **背景**：暗房 + 1m 网格地面，雾收在 9–30m。

## 5. 已知问题

1. **没做阴影**。4.6 要求接触阴影至少 SSAO 级；three 的 `EffectComposer` 不能直接用于 WebXR 双目，留到 Step 2 和键的落地阴影一起解决。
2. **10m 进深下，远端只剩一条线**。分割线在远处会并到一起；如果实际读不出 4 轨，要么加宽轨、要么在远端加一点明度差，要么靠「note 从哪条线出来」来读。
3. **判定带的亮度很难调**。台面本身有台灯形成的高光池，additive 的判定带叠上去容易过曝；现在压到 0.3 / 0.16，偏暗但不再糊成白条。VR 里要再确认。
4. **浮空显示默认位置的依据**：右前方 2.6m、台面上方 0.1m，理由是「看轨道时它就在视野上沿」。如果还是瞄不到，面板里直接拖 X/Y/Z，把数字告诉我。
5. **台面悬空、没有支撑**。目前是刻意的「仪器」处理；如果 VR 里觉得无根，加一根竖梁。
6. **剖切只剩结构，没有零件**。轴承、走线、检修灯带都删了；如果嫌空，可以加回一层。
7. **背景很素**。只有暗房 + 网格 + 渐变；3D 演出属于单曲异象，Step 1 不做。
8. **参数变更是全量重建**。拖滑块会重建台面几何（材质与贴图复用）。
9. **`ExtrudeGeometry` 的 bevel 会向两端各多长一段**，已修；顶板厚度按 `plateThickness` 精确落位。

## 8. 第四版：材质细化（冰 / 玻璃 / 瓷）

这一版只动材质与一块 dev 用的实验台，不改台面尺寸。

### 做了什么

| 材质 | 表面行为 |
| --- | --- |
| **冰** | Worley 晶面法线（40 个细胞）+ 透明混合；基色 `0xb8d6e4`、`opacity 0.42`、`clearcoat 0.55`、`envMapIntensity 0.9` |
| **清玻璃** | 透明混合；基色 `0x9fc0d4`、`opacity 0.32`、`clearcoat 0.6`、`envMapIntensity 1.0`、波纹法线 1.2；管内有光带 |
| **烟熏玻璃** | 同一条波纹管线，更暗、更不透明 |
| **暗瓷** | 釉面低频起伏（法线 0.22）+ 柔和的粗糙度斑；`clearcoat 1.0` |
| **黄铜** | 未改（金属度 1、粗糙度 0.26） |

**阴影**：只让台灯投影，一张 1024² 的 `PCFSoftShadowMap`，不做级联、不开别的光源。样品与台面都参与（`castShadow` / `receiveShadow`）。这是「最简单的方式」，透明物体目前投的是实心影。

- 所有法线贴图都是**程序化高度场求导**得到，可平铺；冰用 Worley（细胞），玻璃用 value noise。
- 粗糙度斑是「被手摸过」的软斑块，不是划痕 —— 对齐 `parallax-idea.md` 4.6 的「使用痕迹」。
- 高度场先归一化再求导，否则距离场的斜率太小，法线几乎是平的（这一版修掉的坑）。

### 怎么看

- **材质实验台**：dev 下默认显示，浮在正前方 0.7m。四件样品自转，上方一盏检验灯。
- 关掉：`?lab=0`，或调试面板「材质实验台 → 显示样品」。

### 已知限制

1. **`transmission` 试过，撤了**。它在「均匀亮台面」这个背景下会变成一块发白的板：亮处透过去是亮的，暗处又没东西可透，结果既不透明也不像玻璃。现在回到透明混合 —— 背后的轨线、台面纹理都能看见。代价是没有真实折射（线不会被折弯）。要折射的话，得先把玻璃放到有对比的背景前，或者等 Step 2 有 note 穿过管身时再试。
2. **透明物体投实心影**。玻璃与冰的阴影和陶瓷一样黑；真实情况应该是透光的浅影。简单做法的代价。
3. **「太白」与「不透明」是同一个旋钮的两端**。基色压深 → 白没了，但透射也没了；基色提亮 → 透，但白。最后选择透明混合 + 冷色基色：透光靠 `opacity`，颜色靠 `color`。两个旋钮分别控制，不再互相打架。
4. **阴影只有一盏灯、一张 1024 图**，覆盖台面前 ~3m；远端没有阴影。
5. **没有环境光遮蔽**，样品之间的遮挡关系靠明暗与法线。
6. **贴图是各向同性的**：玻璃波纹没有方向性，冰的晶面是随机细胞，不是沿锥面生长的棱 —— 近看能看出来。
7. 实验台在 dev 下默认显示，正式玩的时候要 `?lab=0`（或等 Step 2 有真实键后删掉）。

## 9. 键型造型（Step 1 补完，2026-10-17）

四种键型已经做出来了，**只有造型，没有判定 / 生成 / 回收**。

| 键型 | 造型 | 尺寸（米） | 材质 |
| --- | --- | --- | --- |
| **hit** | 横跨轨道的厚条 | 0.21 × 0.055 × 0.075 | 陶瓷（倒角、釉面）：青釉 / 无釉 / 赤釉 |
| **drag** | 横置细条，三枚一串 | 0.195 × 0.011 × 0.022 | 冰（`iceBar`）+ 加法辉光片 |
| **hold** | 贴在轨道上的平片 + 片内亮带 | 0.21（= 轨宽）× 0.006 × 1.2，亮带 55% | 清玻璃 + 发光芯 |
| **arc** | 拱形玻璃管 + 发光芯 + 两层泛光 | 管半径 0.018，拱高 0.34 | 青 / 赤玻璃 + 同色光带 + fresnel 加法壳 |

- 泛光不是后处理 bloom：是包在管外的两层加法壳，用菲涅耳（`1 - |N·V|`）控制强度，所以只在轮廓附近亮。
- arc 的泛光有轻微呼吸（0.4 ± 0.1），只是让「光」看得出是活的，不是节奏。
- drag 不再用锥形：俯视下锥形会被压成一个点，横条才能读出「一串」；辉光是一张水平加法渐变片（壳层会在冰条两端亮成两个点）。
- 位置：hit 三枚并排在 1–3 轨（z ≈ 近端 −0.55），drag 三枚在 4 轨近端（z ≈ −0.62…−0.91），hold 在 4 轨 z ≈ −1.75（长 1.2），arc 两条并排在 2 / 3 轨、z ≈ −1.35…−2.65。

**还没做**：判定输入、手感反馈、生成 / 回收、arc 跟随、端面切角冗余。这些是 Step 2 的主体。

## 10. 手别配色（2026-10-17）

针对「arc 颜色不明显 / hit 与台面对比太低」，把青 / 赤两套手别色落成材质。

| 载体 | 左手 | 右手 | 中性 |
| --- | --- | --- | --- |
| 陶瓷 hit（釉） | 青釉 `#1b363c` | 赤釉 `#431e24` | 无釉 `#5a6067` |
| 玻璃 arc（管壁） | 青玻璃 `#2e6b76` | 赤玻璃 `#743038` | 清玻璃 `#9fc0d4`（hold 用） |
| 管内光带 | `#8ff0ff` | `#ff8fa3` | `#c6e9ff` |
| 泛光壳 / 光斑 | `#2fc4d8` | `#ef2a45` | `#bfefff`（drag / hold 中性光斑） |

- 色值在 `src/materials/palette.ts` 一处定义，材质库与泛光着色器都从这里取；改色只改一个文件。
- **同一个色相有两种取值**：台面的灯很亮（key 2.8 + lamp 30），釉色必须压暗才不会被打成粉彩；玻璃是透明混合，颜色会被洗淡一半，所以玻璃取值更亮更饱和（`glaze` vs `glass`）。
- 中性 hit 用**亮灰瓷**：够亮、能在暗台面上立住，但明度里不带任何色相倾向，不会被误读成某只手。
- 三枚 hit 同一排、同尺寸、同一 z：手别的差别只剩颜色，不掺造型差别，方便直接比色。
- 两条 arc 并排（2 / 3 轨），管壁 / 管芯 / 泛光三层同一色相——玻璃一透，只要缺一层颜色就散。
- 泛光强度：内层 0.75（fresnel power 2.2）、外层 0.3（3.2），两条 arc 同步呼吸。

**还没做**：设计文档要求的「端面切角」冗余（颜色之外的第二编码）、drag 的上色版本、色觉模拟下的一次验证。

## 11. 这一轮（配色压深 / drag 辉光 / hold 改成平片）

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 青釉 / 赤釉 | `#0f6c7d` / `#8f1124`（还是有点糖果感） | `#0a4e5a` / `#6a0f18`（深青 / 酒红，压暗一档） |
| 中性 hit | `#7d838b`（偏亮） | `#5a6067`（更灰） |
| drag | 0.15 × 0.016 × 0.03，无辉光 | 0.195 × 0.011 × 0.022，水平加法辉光片（0.3 × 0.12） |
| hold | 玻璃管 ⌀0.048 × 0.8，内部灌注 | 贴轨平片 0.21 × 0.006 × 1.2，片内亮带 55% |
| arc 管壁 | opacity 0.42（太透） | 0.58（中性玻璃也 0.32 → 0.45） |

- drag 的辉光**没有用壳层**：薄片键的菲涅耳壳层会在近端 / 远端两个面上爆亮，读起来像两个端点在发光。改成一张水平铺开的加法渐变片（`createGlowTexture`），从上方俯视时是一圈柔光，不会破坏「细条」的轮廓。
- hold 的亮带**不是盖一层白板**：之前用整宽的发光片，结果读成一块白色面板。现在是 0.07 宽的窄带，才是「片子里被点亮的那一段」。
- 设计文档已同步：hold 从「光滑玻璃管 + 管内液体」改为「光滑玻璃片 + 片内推进的亮带」，§2 / 4.1 / 4.2 / 4.3 与修订记录都改了。

**待你判断**：hold 平片的**长边**（沿轨道方向）现在是 1.2m；如果你说的是「长宽都 ≈ 轨宽」（0.23）的小方片，改 `holdLength` 一个常数即可。

## 12. 第三次配色收敛 + hold / arc 辉光

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 青釉 | `#1f4d55` | `#1b363c` |
| 赤釉 | `#53262d` | `#431e24` |
| 青玻璃 / 赤玻璃 | `#2c7482` / `#7a2530` | `#2e6b76` / `#743038` |
| hold | 无辉光 | 片底一张加法渐变片（0.42 × 1.5） |
| arc | 两层菲涅耳壳 | 壳 + 台面光斑（0.3 × 1.7，带手别色） |

**配色**：两轮都往「压暗」走，这一轮改成**降饱和**。实测全身平均色：

| | 渲染色 | 饱和度 | 明度 |
| --- | --- | --- | --- |
| 青釉 | `#487b8f` | 49% | 56% |
| 赤釉 | `#783e52` | 48% | 47% |
| 无釉 | `#a0aebf` | 16% | 74% |

从「霓虹」退到「深色釉」：颜色还在，但不抢眼睛。中性仍是亮度最高的一条——这是刻意的：无釉瓷本来就比带釉的亮，玩家读「这条不锁手」靠的就是这点亮度差。

**辉光**：hold / arc / drag 现在用同一套加法渐变片（`createGlowTexture`），差别只在摆法：

- drag：贴在冰条下方，0.3 × 0.12；
- hold：压在平片底下，玻璃半透，光从片里透出来；
- arc：铺在轨道上，跟着弧的色相（青 / 赤），读作「光从弧上洒下来」。

arc 的两层菲涅耳壳保留，但半径收到 0.032 / 0.062、功率提到 2.0 / 2.6——只负责勾一圈边。试过把外圈放大到 0.09、功率 1.15，结果不是辉光，是一层「玻璃斗篷」。

### 判定（按 `parallax-idea.md` 2：只看速度 / 距离 / 时间）

| 量 | 取值 | 备注 |
| --- | --- | --- |
| 接触盒 | x ±0.11 · y ±0.20 · z ±0.10 m | x 略小于半轨宽；y 给手腕留足余量（穿戴着控制器扫，不会正好在 1.02m） |
| 速度阈值 | 0.45 m/s | 低于它只算「碰到」，不算扫过 |
| 可打窗口 | 判定带 ±0.45 m | 防止提前伸手抓远处的键 |
| 漏 | 越过判定带 0.5 m 仍未碎 | 冰条继续滑出去，不消失、不爆炸 |

- 冰条尺寸 0.195 × 0.011 × 0.022，和键型预览一致；中心高出台面 0.07m。
- 流速 3 m/s，楼梯间隔 0.22s，第一颗提前 1.35s 出生 → 一波约 1.3s 打完，停 1.3s 再来。
- 判定偏移按 `(z - bandZ) / 流速` 换算成毫秒：≤90ms 完美 / ≤200ms 好 / 其余命中。

### 反馈

- 命中：冰条立刻消失，原地炸 12 片四面体碎屑（带重力、自转、淡出）+ 一批加法霜雾点，初速方向取手的运动方向。
- 漏：什么都不发生——冰条完整滑过去，这是设计文档要的「没碎」。
- 手有一条 14 点的加法拖尾，扫的时候能看见轨迹。
- 命中时给那只手一记短促触觉（`hapticActuators[0].pulse(0.55, 45ms)`）；手柄不支持就静默跳过。

### 怎么测

- **VR**：`adb reverse tcp:5173 tcp:5173` → Quest 浏览器打开 `http://localhost:5173` → Enter VR。进头显会自动重开一波。控制器横扫 1–4 轨，扫到哪条碎哪条。
- **桌面**：鼠标在画面上**左右快速横扫**（手固定在判定带高度与 z），也能扫碎。
- 诊断面板新增 `drag 命中 / 漏` 与 `last judge`（带毫秒偏移）。
