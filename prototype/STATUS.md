## 1. 这一步做了什么

腰高台面成立，默认 4 轨窗口，深色材质与剖切边到位。**没有键型、判定、shift 动画、谱面。**

- **台面**：6 条铣出的导轨槽（0–5），默认只显示 1–4；0 / 5 用盲板盖住，盲板下方垫一圈板缝。
- **槽**：宽 160mm、深 26mm；内壁有衬板（比台面暗），槽口有 AO 渐变带。
- **导轨**：5 条 4mm 高的凸起铝条 + 镜面倒角条。
- **判定带**：槽底冷白亮带（柔光 + 芯线），静态、贴槽底。只有可见轨有。
- **剖切**：近端整面 + 右侧近半段敞开（远半段保留外壳，读成「切开」而不是「缺一面」）。内部有承力底板、中层甲板、四根纵筋、横向梁、三组轴承与轴、三根走线、两条检修灯带；切面有 6mm 倒角框和筋 / 甲板 / 底板的断面端头。
- **材质**：程序化。黑阳极铝台面（拉丝）、机加工铝、镜面倒角、黄铜、暗瓷、烟熏玻璃、冰。
- **环境**：程序化 PMREM —— 暗房 + 顶部冷白灯带 + 侧灯带 + 身后弱光板（金属反光靠它，不靠单光源）。
- **光照**：主光 + 轮廓光 + 台灯（SpotLight）+ 腔体补光。
- **HUD 托架**：右侧占位铭牌，**世界固定**。
- **样品盘**：左侧一块侧托板上，四块材质样品 + 刻字标签（Step 1 测试道具）。
- **背景**：暗房 + 1m 网格地面 + 远处渐变，无 shader 演出。
- **调试面板**：台面 / 布局 / 表现三组，改任何尺寸立即重建。

## 5. 已知问题

1. **没做阴影**。`parallax-idea.md` 4.6 要求接触阴影至少是 SSAO 级别，且不能用投影贴片；three 的 `EffectComposer` 不能直接用于 WebXR 双目渲染，所以这一步先不做，等 Step 2 有键之后再单独解决。
2. **台面在灯下偏浅**，不是纯黑阳极。纯黑金属 + 暗环境 = 全黑，槽就读不出来；现在用「深灰阳极 + 台灯」折中。可用面板的曝光 / 环境强度再压暗，或改 `library.ts` 的 `topPlate`。
3. **判定带在桌面上略像浮线**。它确实贴在槽底（低 26mm），有柔光晕；但 2D 截图里的辉光会读成发光条。**VR 里需要确认它读成「槽底的一段亮带」。**
4. **HUD 托架是世界固定**。§1 ⑥ 的未决问题（世界 vs 视野）仍然未决 —— 这一步选了世界固定，代价是玩家可能找不到。
5. **样品盘是测试道具**。Step 2 有真实键型之后应撤掉；它现在承担「陶瓷 / 冰 / 玻璃 / 黄铜」的验收。
6. **背景很素**。只有暗房 + 网格 + 渐变。5.3 允许 3D / shader 演出，但那是单曲异象的事，Step 1 不做。
7. **参数变更是全量重建**。拖滑块会重建台面 / HUD / 样品盘三组几何（材质与贴图复用）。dev 够用，不值得优化。
8. **ExtrudeGeometry 的 bevel 会向两端各长出一段**，导致顶板实际表面比 `topY` 高 2mm。已修（挤出深度减 2×bevel，再整体下移）。**所有贴在表面的东西（AO 带 / 盲板 / 板缝 / 轨号 / 螺钉）都依赖这个修正**——后续加面装饰时别再踩。

## 7. 下一步（等你验证 Step 1 之后才动）

**请戴头显看四件事**：

1. 一眼能不能数清 4 条轨；0 / 5 的盲板会不会误导成「第 5、6 条轨」。
2. 槽的深度与侧壁是否读得出来；判定带像不像「亮着的槽底」而不是浮线。
3. 剖切边像不像「被切开的仪器」；腔体内部能不能读出层次。
4. 台面高度 / 轨距 / 槽宽在体感上合不合适（站着伸手够不够自然）。

把结论告诉我，我再进 **Step 2 — 四种键型**。如果某些尺寸要改，直接给数字，比在面板里试更快。
