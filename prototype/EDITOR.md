# Parallax 制谱器（Step 5）

> 入口：`http://127.0.0.1:5173/editor.html`（独立页面，不进 VR）。
> 谱面格式：[`CHART.md`](CHART.md) ｜ 进度与坑：[`STATUS.md`](STATUS.md)

制谱器只做一件事：**把同一份 `Chart` 数据画出来、改掉、再用 Step 4 的播放器验一遍**。
它不复制播放器，也不定义第二套格式 —— 导出文件就是游戏页读的那种 JSON。

---

## 1. 打开

```bash
cd prototype
npm run dev
```

- 游戏：<http://127.0.0.1:5173>
- 制谱器：<http://127.0.0.1:5173/editor.html>

第一次打开是空谱（150 BPM / 4 拍）。右侧 `CHART` 里有 **LOAD TEST / LOAD DEMO**，
可以直接载入内置的 41.6 秒验收谱或 12 秒示例再改。

编辑内容每 650ms 自动写进 `localStorage`（`parallax.editor.draft.v1`），刷新不丢；
音频文件不会进草稿（浏览器不能持久化本地文件），刷新后需要重新导入。
调试时可以加 `?fresh=1` 忽略草稿、从空谱开始。

## 2. 界面

```
┌ 顶栏：工具 / 时间 SNAP / SNAP XZ / 3D EDIT / 2D / 缩放 / 文件 ┐
├──────────────┬─┬────────────────────────────┬──────────────┤
│ 3D 预览      │↕│ 2D 俯视图                   │ 检查器        │
│ （可直接编辑）│ │  标尺 / 6 轨 / 高度 / SV     │ 选区 / 事件   │
│ + 走带        │ │  波形（最底下）              │               │
└──────────────┴─┴────────────────────────────┴──────────────┘
```

- `2D` 按钮关闭 / 打开 2D 俯视图；预览和 2D 之间的细条可以左右拖动改宽度。
- 波形放在时间轴**最底下**，紧挨 SV 轨。
- 3D EDIT 默认开启：左键在 3D 里放置 / 拾取拖动，右键拖拽转视角。
- `GUIDE`（顶栏，默认开）：竖直引导网。它只在 hit 接近时点亮，网格和 3D 编辑网格同一套
  （竖线 1/4 轨、横线 5cm，整轨 / 10cm / 胸 / 面 / 头顶加亮）；关掉后完全不画。

### 3D 预览（可编辑）

- 直接跑 `src/game/player.ts`：note 生成、SV 积分、shift、判定、自动打都是真的。
- **3D 编辑**：
  - 空处左键 = 在**播放头时间（按 SNAP 吸附）**、鼠标对应的 x / z 放置；
  - ARC 空处拖 = 起点钉在点击处，拖的是**终点**；拖拽期间终点临时放在 1ms（和起点同平面），
    所以是 1:1 跟鼠标；松手后终点时间落到 500ms，要改时长去 2D / 检查器；
  - 已有 note = 拖动 x / z（时间不变）；hold 只改 x；
  - **arc 编辑层**：选中弧后，白球 = 自由 x/z，青球 = 只改 x，黄铜球 = 只改 z；
  - ARC 工具点弧身 = 在该时间（SNAP 吸附）插一个点并直接拖着走；
  - 点弧上的物量珠 = 直接切 KEY（AUTO 物量会先转成显式 `ticks[]`）；
  - 拖动时编辑层按同一套滚动公式**实时重建**，播放器里的旧弧几何临时隐藏；
  - 播放时编辑层隐藏，回到普通预览；暂停后恢复。
- **虚拟网格 + 落点环**：鼠标进入 3D 时出现，显示轨中心 / 轨边界、5cm 高度线、
  胸 / 面 / 头顶三条亮线；光标在网格上有一个**吸附后的落点环**，所见即所得。
  `SNAP XZ` 打开时，地面键 x **吸整轨**、z 吸 5cm；arc x 吸 1/4 轨。
  `Ctrl / Cmd` 临时自由；关掉 `SNAP XZ` 就全程自由；`Shift` 把 z 吸到 0 / 胸 / 面 / 头顶。
- **按需重绘**：暂停且没有操作时，3D、2D、底部总览都不再每帧重画；播放 / 拖动 / 悬停才推帧。
- **AUTO**：播放时所有 note / 物量到达判定线直接判 PERFECT，不再模拟移动光点；暂停时不判。
- **FOLLOW**：播放头跑出视口右侧时自动滚动时间轴；关掉就完全手动。

### 底部全局时间线（Blender 式）

- 最底下一条横贯全窗口的时间线：整首谱概览、note 密度、shift / SV 标记、播放头。
- **点击 / 拖动空白处 = scrub**（自由毫秒，不吸附）；播放头跟着走。
- 视口框对应当前 2D 时间轴的范围；拖它**顶部的黄铜 handle** 平移 2D 视图。
- 左侧 `▶` / 时间读数与主走带同步。

### 走带

| 控件 | 行为 |
| --- | --- |
| `▶ PLAY / ❙❙ PAUSE` | 播放 / 暂停。空格同效 |
| `⏮` | 回到 lead-in（−1s）并暂停 |
| `RATE` | 0.25× / 0.5× / 0.75× / 1× / 1.5× / 2×；改变谱面时间 / 音频 |
| `3D SPEED` | 0.5–10 m/s 的 3D 视觉流速；**不改 SV、判定、音频或时间** |
| `REV` | 倒放（R 键同效） |
| `AUTO` | 自动完美（到判定线直接 PERFECT） |
| `FOLLOW` | 自动滚动时间轴 |
| `DRUMS` | 没有音轨时的合成鼓组；编辑器默认**关**，勾上才响 |

**时钟**：1× 正放时用**音频时钟**（`AudioContext.currentTime`，含输出延迟补偿），
和游戏完全一致；慢放 / 快放 / 倒放时音频不可能跟着走，自动切成手动时钟并静音，
走带上的音频标签会显示 `FREE`（手动时钟）或 `LOCK`（音频时钟）。

## 3. 时间轴怎么读

| 带 | 横轴 | 纵轴 | 内容 |
| --- | --- | --- | --- |
| 标尺 | 时间 | — | 小节号、时间刻度、shift 标记（← 青 / ● 黄铜 / → 赤） |
| **主视图** | 时间 | **6 条轨（0–5）** | hit / drag / hold / arc 的连续 x |
| **高度轨** | 时间 | **0–0.9m** | 所有 note 的 z；胸 0.33 / 面 0.61 / 头顶 0.81 三条基准线 |
| **SV 轨** | 时间 | 倍率 | 变速曲线（1× 是黄铜虚线；负值在下面） |
| 波形 | 时间 | 振幅 | 导入音频的包络（已按 `meta.offset` 平移，放在最底下） |

- x 是**连续**的：0 号轨中心 = 0，台面中心 = 2.5，5 号轨中心 = 5。
  主视图的 6 条轨只是参考线，note 可以落在 3.25 这种轨与轨之间。
- 主视图里**高亮的 4 条轨**就是当时的 shift 窗口（1–4 / 0–3 / 2–5），
  它随时间连续滑动；左侧轨号只在窗口内的 4 条上亮起。
- 不在窗口内的 note 会带一个**红点**，右侧 `VALIDATION` 同时报错。
- 空中的 hit / drag 在主视图上多一个向上的小三角；精确高度看高度轨。
- **高度轨**：arc 是曲线，hit / drag 是点；hold 固定贴地，不参与高度编辑。
- 选中对象时会出现白色竖线；arc 选中后，主视图和高度轨同时显示所有顶点。
- 导出的谱面可以直接放在 `prototype/public/charts/`，游戏页用
  `?chart=/charts/文件名.json` 打开（示例：`/charts/example.json`、`/charts/air-example.json`）。

## 4. 编辑操作

工具用 `1–5` 或顶栏按钮切换。

### 放置

| 工具 | 操作 | 结果 |
| --- | --- | --- |
| HIT | 左键点空处 | 在吸附点放一颗 hit |
| DRAG | 左键点空处 | 放一颗 drag |
| HOLD | 左键**拖** | 起点 = 按下点，终点 = 松手点（至少一格） |
| ARC | 左键**拖** | 两点弧：起点 → 终点，初始高度 0 |
| 任意工具 | 3D 左键点空处 | 在播放头时间、对应 x / z 放当前工具的 note（hold 强制贴地） |

- 2D 放置：地面键 x **默认吸整轨**；`Ctrl / Cmd` 临时离轨；`SNAP XZ` 关掉全程自由。z 用类型默认。
- 3D 放置：x / z 来自鼠标在播放头平面上的落点；地面键默认整轨，arc 1/4 轨；`Shift` 吸高度基准线。
- 放置时按住拖动可以继续调时间 / x / z；松手前不会进预览。`Ctrl / Cmd` 临时关掉所有吸附。

### 选中 / 移动

`SELECT` 工具：

- 点 note → 选中；左右拖改 **时间**，上下拖改 **x**（默认整轨，Ctrl 自由）。
- **多选**：`Shift + 左键` 点 note 加选 / 取消；再拖任意一个已选中的 note，整组一起移动
  （时间、x 一起走；高度轨里拖则整组 z 一起走）。整组只吸附抓住的那一颗，
  其余加同一 delta，组内相对间距不变。Shift 点空处不会放置新 note。arc 顶点仍是单点选择。
- hold：拖**尾部**改 duration；拖身体移动整条。
- arc：拖**身体**移动整条（时间 + 所有点的 x）；拖**顶点**改顶点的时间 / x。
- 高度轨：拖 hit/drag 的**点**、arc 的**顶点**改 z；Shift 吸附到 0 / 胸 / 面 / 头顶；
  拖 arc 身体是整条上下平移。**hold 固定贴地，不能在高度轨拖。**
- 3D：点 note 直接拖 x / z；hold 只改 x。选中 arc 的点后拖白球 = x+z，
  拖青球 = 只改 x，拖黄铜球 = 只改 z；拖弧身 = 整条平移。
- 3D 里 arc 点的**时间**不拖；用 2D / 检查器改时间。拖点只改形状。
- SV 轨：拖点只改倍率（拖动范围 = 当前纵向显示范围，极端值用检查器输入）；
  时间 / 过渡时长 / 缓动在右侧检查器改。
- 标尺上的 shift 标记可以点选、左右拖动改时间。

### arc 的点列与缓动

- ARC 工具在**主视图点住已有弧身**：在该时间插入一个点并直接拖着走。
- ARC 工具在**高度轨点住已有弧**：在该时间、该高度插入一个点。
- ARC 工具在 **3D 点住已有弧身**：在该时间（SNAP 吸附）插入一个点并直接拖着走。
- 检查器列出全部顶点：`# / time / x / z / EASE X / Z`。点一行选中它；
  非首点可以分别改 **X（横向）** 和 **Z（高度）** 的缓动；Z 选 `SAME AS X` 时跟随 X：

| 值 | 形状 |
| --- | --- |
| `直线` | 匀速；连续两段直线 = 直角 / 钝角 |
| `缓入` | `sin(πu/2)`，慢起快收 |
| `缓出` | `1 − cos(πu/2)`，快起慢收 |
| `缓入缓出` | `cubic-bezier(1/3, 0, 2/3, 1)`，即 smoothstep |

- 例：`EASE X = 直线`、`EASE Z = 缓入` → 横向匀速、高度缓入；
  反过来也可以。旧谱面的单 `easing` 仍同时作用于 X / Z。

- 首点的 `time` 恒为 0；拖首点会移动整条弧的起点（`note.time`）。
- 末点的 `time` 就是弧长。
- 缓动和 arc 形状用的是**和播放器同一份** `src/chart/easing.ts`。
  运行时的管是折线：`linear` 段是直线，直角是硬角，不会被 Catmull-Rom 磨圆。
  `STRAIGHTEN` 一键把所有段设为 `linear`。

### arc 的物量（ticks）

- 默认是 **AUTO**：普通物量按 `OBJECTS/S` 均匀生成，再叠加 `KEY OBJECTS`。
- **3D 里直接点弧上的物量珠**：普通珠变黄铜珠 = KEY，再点一次取消；AUTO 会先转显式。
  如果 KEY 正好和控制点重合（白球盖住珠子），用检查器的 `MAKE / REMOVE KEY @ POINT`。
- `MAKE EXPLICIT` 会把当前物量转成显式 `ticks[]`；之后可以在检查器里：
  - 逐条改时间、勾 / 取消 `KEY`、删除；
  - `+ TICK` / `+ KEY` 在播放头时间加一条；
  - `AUTO` 回到自动生成。
- **没有 tick 的时间就没有物量**。直角蛇的拐角如果不需要结算，就不要在拐角放 tick；
  手只需要大致划过，判定只发生在有 tick 的时刻。
- 主视图 / 高度轨会把普通 tick 画成小点、关键 tick 画成黄铜菱形。

### 删除

- **右键**光标下的 note / arc 顶点 / SV 点 / shift 标记：直接删。
- `Delete` / `Backspace`：删当前选区。选中 arc 端点时删整条弧；
  选中中间点时只删那个点。

### 插入点列

arc 的点列就是 `points[]`；可以任意多段，每段一个缓动。
想要「直角」就连续两段 `linear`；想要曲线就改后一段的缓动。

## 5. 时间吸附与网格

时间吸附是**预设 + 自定义参数**，不再枚举一长串下拉项：

| 控件 | 含义 |
| --- | --- |
| `SNAP` 预设 | OFF / 1/4 / 1/8 / 1/12（三连）/ 1/16 / 1/20（五连）/ 1/24 / 1/32 —— **随拍号变** |
| `DIV` | 每全音符分几份：8 = 1/8，20 = 1/20；可以直接填任意 1–64 |
| `DOT` | 附点，×1.5 |
| `3` | 三连，×2/3 |

- **预设跟着拍号走**：分母就是基准拍，k = 每拍细分几份，列表是 `1/d · 1/2d · 1/3d（三连）· 1/4d · 1/5d（五连）· 1/6d · 1/8d`。
  `4/4` → 1/4、1/8、1/12、1/16、1/20…；`5/6` → 1/6、1/12、1/18、1/24、1/30…；`3/4`、`6/8` 同理。
  当前 DIV 不在新拍号的预设里时，下拉会显示 `CUSTOM · 1/8`，不会静默改掉你的吸附。
- 吸附步长 = `4 / DIV` 个**四分音符**，再按 DOT / 3 乘系数；因为标签是“每全音符几份”，
  在 `5/6` 里选 `1/8` 就是 0.75 拍，和网格线严格对齐。
- 例如：五连 = `DIV 20`；附点八分 = `DIV 8` + `DOT`；三连八分 = `DIV 8` + `3`（也等于 `DIV 12`）。
- 改了 DIV / DOT / 3 后下拉框显示 `CUSTOM`；再点任意预设就回到预设。
- 网格基于 `timing` 的拍号：检查器里每个 timing 点有 `N / D` 两个输入（`4/4`、`5/6`、`4/3` 都行），换段时按段重新起拍，小节线 / 拍线 / 细分线一起重算；
  小节编号跨段连续累加；小节线即使不被细分步长整除也会单独补画。
- 换拍号可以直接落在小节中间：把新 timing 行的 `TIME` 写成毫秒即可，前一小节会被截短、
  编号保留，下一段从下一个编号接着走。
- 状态栏实时显示播放头所在的 `N/D · BAR n`，播放中换拍号会立刻跳变。
- 拖动、放置、播放头移动、shift / SV 点的时间、**3D 放置 / 3D 弧上插点**都用同一个吸附函数。
- 显示：小节线较亮，拍线次之，细分线更暗；细分间距小于 7px 时自动不画。
- 150 BPM 下一拍 400ms：`DIV 8` = 200ms，正好是内置验收谱的网格。
- `Ctrl / Cmd` 拖动 / 点击 = 临时关掉时间吸附（写五连、附点时不用改参数）。

**空间吸附是另一条开关 `SNAP XZ`**：

- 地面键：x 吸整轨（写谱规矩）；离轨用 `Ctrl / Cmd` 临时关掉，或直接改检查器 X；
- **空中 hit / drag**（z > 0.07m）：x 和 arc 点一样吸 **1/4 轨**，不再强制整轨；z 仍吸 5cm；
- arc：x 吸 1/4 轨（弧是自由曲线）；z 统一吸 5cm；
- 关闭 `SNAP XZ`：x 保留到 0.01 轨、z 保留到 0.001m，完全自由；
- 按住 `Shift`：z 强制 0 / 胸 / 面 / 头顶；地面键 x 强制整轨；
- 虚拟网格本身始终在鼠标进入 3D 时显示，`SNAP XZ` 只决定吸不吸。

## 6. 音频、offset 与波形

右侧 `AUDIO`：

- **TRACK**：选择本地音频（也支持把音频文件拖进页面）。会读 FLAC / MP3 的内嵌封面、
  标题、作者；没有封面时在 `COVER` 里手动选图片。解码后：
  - 波形画在时间轴**最底下**的波形带里；
  - 预览播放会用它当音轨（1× 正放时）；
  - 找不到文件 / 解码失败会在 `VALIDATION` 上方显示错误。
- **OFFSET (ms)**：就是 `meta.offset`，**谱面作者的音频偏移**；不是玩家校准。
  **正值 = 谱面时间比音频提前**。游戏 Settings 的 Offset 是玩家校准，运行时两者分开（`chartOffsetMs` / `offsetMs`）。波形会跟着左右平移：
  谱面时间 `t` 处画的是音频 `t − offset` 的采样。
  用 `−10 / −1 / +1 / +10` 微调，把鼓点 / 人声对齐到小节线。
- **DURATION (ms)**：谱面 / 音轨时长。导入音频时自动设为音频长度；也可以手动改。
  `AUDIO LENGTH` 一键恢复成当前音轨长度。时间轴和游戏进度都按它显示。
- **COVER**：音频内嵌封面（FLAC / MP3）；没有就显示 `NO COVER`，可以手动选图片。
- **SPECTRUM**（顶栏）：展开音频频谱。与 2D 视口共用时间范围，指针点击 / 拖动直接
  `seek`，收起面板后播放头不变；滚轮平移，Ctrl+滚轮缩放。用来找鼓点 / 钢琴 / lead。
- 没有音频时，预览可以按 `timing` 现场合成鼓点，照样能对拍；编辑器默认关，走带上的 `DRUMS` 勾选后才响。
- 音量 / 节拍器只影响预览，不写进谱面。

> 音频 / 封面文件不会保存进 JSON / localStorage。`.parallax` 会把它们打进包里；
> 单独导出的 JSON 只记文件名，游戏里需要 `?audio=/你的音频.mp3`。

## 7. 存档 / 导出 / 导入

| 动作 | 结果 |
| --- | --- |
| 自动 | 每次改动后 650ms 写 localStorage 草稿；关页面前再写一次 |
| `EXPORT` / `Ctrl+S` | 下载 `<title>.parallax` 谱面包（谱面 + 当前音轨 + 保留资源） |
| `JSON` | 下载旧的 `<title>.parallax.json`（调试 / 兼容） |
| `IMPORT` | 读入 `.parallax` 或 `.parallax.json`；包内音频 / 封面会自动恢复 |
| `NEW` | 空谱（有内容时确认） |
| `LOAD TEST / LOAD DEMO` | 载入内置验收谱 / 12 秒示例 |

## 9. 校验与限制

右侧 `VALIDATION` 实时跑 `validateChart`，顶栏同时显示问题数：

- 地面键的 `lane` 必须是 0–5 的整数（兼容字段）；有效 `x` 必须在**当时的连续窗口**里
  （常态 `[0.5, 4.5]`，左移 `[−0.5, 3.5]`，右移 `[1.5, 5.5]`）；
- hit/drag/arc 的 `z` 在 `0–limits.maxHeight` 之间（默认 0.81m = 头顶线）；hold 必须贴地；
- arc 至少两个点、首点 time = 0、点时间递增、x / z 范围；
- 显式 `ticks[]` 必须落在弧长内、按时间递增且不重复；旧 `keyObjects` 同样检查；
- timing / speed / shift 的排序与取值范围；
- notes 建议按时间排序（编辑器每次改动都会自动排序）。

校验只是提示，**不会阻止编辑**；超限的 arc 在播放器里不会生成（和游戏一致）。
高度上限可以在谱面里覆盖：

```jsonc
"limits": { "maxHeight": 0.81 }
```

## 11. 已知限制

- 波形没有单独的缩放 / 视图：缩放时间轴时波形跟时间轴一起变。频谱是顶栏 `SPECTRUM` 的独立面板（见 §6）。
- 没有 BPM 检测 / 自动对齐；BPM 和 offset 手动填。
- 还没有自由拍号（`n/d`）与随拍号变化的网格 / 下拉菜单；当前 `timing` 只有整数 `beats`/小节。
- 新谱默认难度为空：tier + level 由作者在 `DIFFICULTY` 里显式填。tier 主题色已定稿，但编辑器还没有 tier 选择器 / 徽章。
- 没有复制粘贴 / 框选；多选只覆盖 note，arc 顶点仍是单点编辑。
- 没有 section 标记编辑（导入时会保留）。
- arc 的中间点插入会继承后一段的缓动，曲线在插入点处可能有很小的形状变化。
- 3D 里 arc 的点可以改 x / z（白 / 青 / 黄铜球），但**点的时间**仍要在 2D 或检查器里改。
- 3D 放置的时间 = 播放头时间按 SNAP 吸附；要放到别的时刻，先移动播放头（2D 标尺 / 箭头）。
- KEY 与控制点完全重合时，点击会优先选中控制点；用检查器的 `MAKE / REMOVE KEY @ POINT`。
- 音频只存在于当前页面会话；刷新 / 换设备后要重新导入。
- 预览的 1× 正放用音频时钟，**慢放 / 倒放是静音的**（AudioContext 不支持倒退）。
- 3D 预览按窗口大小渲染，窄窗口里视野比头显窄；它验证的是谱面，不是视场。
- hold 固定贴地，不能飞天；hit / drag 可以浮空。

## 12. 做一段谱的推荐流程

1. `AUDIO` 导入音轨；用 offset 把第一个重拍对到 `0:00` 的小节线。
2. 填 `TITLE / DIFFICULTY`，`TIMING` 确认 BPM 和拍数。
3. `SNAP` 选 `1/8`（或更细），先用 HIT 把主旋律 / 鼓点铺一遍。
4. 加 HOLD / ARC；用 3D 视图把 hit/drag 直接放到空中 / 轨间（hold 只能贴地）；
   在高度轨把 arc 抬到胸 / 面；`MAKE EXPLICIT` 后只保留需要结算的 arc 物量。
5. `SHIFT` 在段落切换处加窗口移动；`SV` 在需要停顿 / 加速的地方加点。
6. 按 `Space` 用 1× 跑一遍，再用 0.5× 看判定与视觉；`REV` 检查后半段。
7. `EXPORT` 得到 `.parallax`：
   - 最快：打开游戏页，左下角 `LOAD .parallax` 选这个文件（或拖进去），直接开始；
   - 或放进 `prototype/public/packages/`，用 `?pack=/packages/…parallax` 打开；
   - Quest 上用同一 URL（`adb reverse` 已配好）。
